# 真实账户收益与评判方法适用性

当前结论是：可以核验“账户收益有没有算对、现行统计程序有没有算对”，但不能仅凭这两项核验颁发“这个方法对真实市场有效”的证书。

## 本次交付

`method_applicability_v1.py` 为已暴露的完整历史五候选家族提供一个有限、可重复的只读诊断入口。首次读取账户前冻结范围：一个方法、五个候选、每个普通及压力成本账户，加一个共同基准，总计十一账户；不重跑账户、不调用模型、不增加独立确认机会，也不搜索其他方法。

调用顺序：

```python
from chanlun_trader.research_factory.method_applicability_v1 import (
    freeze_diagnostic_scope, diagnose_settled_family,
)
freeze_diagnostic_scope(preregistration_path, accounts_root)
report = diagnose_settled_family(
    accounts_root, calibration_path,
    preregistration_path=preregistration_path,
)
```

重复读取相同冻结范围只会重算同一份诊断，不增加研究机会。源码、范围、方法或预算描述发生变化时，已有冻结文件不能被静默覆盖。

## 核验了什么

1. 复用既有开始、结算、确认和已消费预算记录，核验账户身份，不接受只有收益摘要的材料。
2. 从独立核账的净值重算逐日净收益，与保存的收益及指标逐项对照。全部候选必须与买入持有基准使用同日、同输入。
3. 复用成本核验，绑定全部账户的策略规则、窗口、股票池、资金、执行假设与结果哈希。删除失败候选不能减少家族。
4. 复用正式服务 `_load_method` 检查现有完整校准及已批准哈希，没有新增可以由调用方勾选的批准参数。
5. 用 Python 标准库均值、样本标准差，以及独立的 t7 密度积分路线重新计算 p 值和 Holm 校正，交叉检查现行不完全 beta 函数实现。数值一致不代表市场假设成立。
6. 展示八组均值、两个半段均值、自相关、四阶矩、空仓对应的零超额比例及成本表现。这些都是描述，不是适用性通过门槛。

报告保留原有限合成校准的置信界和检出能力摘要，并明确区分直接构造的收益过程与引擎实际生成的历史账户。这里没有新增引擎零假设模拟校准，不能把已知历史收益当作误报率实验。

## 为什么仍然阻断

现行 V2 检验的是共同预期每日净简单超额收益是否大于零，依赖组均值具有共同期望、近似独立且近似正态。有限历史窗口无法证明这些条件长期成立。自相关检验不显著、分组看起来平稳或者回测赚了钱，都不是独立性和共同均值的证据。

因此当前报告明确返回 `INSUFFICIENT_EVIDENCE`，保留 `REAL_RETURN_PROCESS_APPLICABILITY_NOT_ESTABLISHED`，不写入正式资格库，不放行 Paper。它是可核查的阻断解释，而不是支持证书。

已有 V2 校准只覆盖冻结的有限生成过程。其五候选、504 日及旧执行范围不能自动扩展到更大股票池、资金、策略表达或不同分红处理。新范围必须重新研究对应的收益过程。

## 后续方法研究边界

如另选方法，应先冻结新的版本、净超额收益目标、零假设、样本条件、方法选择额度、家族和跨批错误预算、随机种子、误报置信上界、检出能力以及失败后的停止规则，再运行独立数值核对和真实引擎生成过程的校准。未完成校准不接正式资格。

超鞅与随时有效推断可以在有条件均值及过程假设时提供另一条研究路线，但不能凭名称消除假设，也不能将净收益悄悄改为截断收益或胜率。相关原始来源：[JRSS B 原始论文](https://academic.oup.com/jrsssb/article/86/1/1/7043257)。本交付没有实现或批准该替代方法。
