# SAFE_RUNTIME_CONTEXT_V1

## 用途

`SafeRuntimeContextV1` 是按 Objective 构建的只读研究运行时视图，统一供 AI Research Design、Candidate Proposal、人工 AI Handoff 以及后续研究工具使用。它只读取 canonical 资料和对账结果，不创建 Candidate、Trial、预算预留、AI 调用或研究状态。

上下文是结果盲化的：只提供目标状态、研究机制约束、数据/因子/事件能力、Candidate/Trial 治理身份、预算治理摘要、结构预检的样本可行性与完整性摘要，以及抽象失败分类。禁止携带收益、胜率、回撤、PF、p-value、Sharpe、交易明细、净值或其他预测结果数值。

## 权威边界

- 第一读取步骤是 `ObjectiveReconciliationServiceV1`。`CANONICAL_CONFLICT` 会封锁上下文；预算权威来源不唯一时返回 `BUDGET_AUTHORITY_AMBIGUOUS`。
- daemon、orchestrator 和 console 只作为 `runtime_projection` 健康信息，不覆盖 Objective、Candidate、Trial、预算或 Structural 的 canonical 事实。
- AI Design 使用 `purpose="AI_DESIGN"`，Candidate Proposal 使用 `purpose="CANDIDATE_PROPOSAL"`，避免派生工件把自身写入输入哈希；两者仍共享同一 Builder 和 canonical 事实边界。
- Candidate Proposal 持久化 `source_context_id` 与 `source_context_hash`。重新读取、冻结或执行合同物化前会重新校验安全上下文；canonical 事实变化时以 `STALE_RUNTIME_CONTEXT` 失败关闭。

## 新鲜度与身份

上下文身份包括 `context_id`、`context_version`、Objective 状态哈希、canonical source hashes、预算/Candidate/Structural 组件哈希、生成时间、有效截止时间和 `context_hash`。时间窗口用于过期判断，不会使同一组未变化的 canonical 事实在重复读取时产生伪变化。

`validate_context_freshness()` 会重新读取并检查 Objective 状态、Candidate、预算、Structural、数据 manifest、因子能力和事件能力组件；任何变化都会阻断后续 AI、Handoff 或 Candidate 操作。

## 只读接口

HTTP：

```text
GET /api/research-console/{objective_id}/safe-runtime-context
```

命令行摘要：

```text
python -m chanlun_trader.research_factory.safe_runtime_context --root . --objective-id <OBJECTIVE_ID>
```

机器 JSON：

```text
python -m chanlun_trader.research_factory.safe_runtime_context --root . --objective-id <OBJECTIVE_ID> --json
```

如需保存派生审计快照，必须显式指定项目内路径；该文件标记为 `DERIVED_READ_MODEL`，不能作为 canonical 权威来源：

```text
python -m chanlun_trader.research_factory.safe_runtime_context --root . --objective-id <OBJECTIVE_ID> --json --output reports/research_context/<OBJECTIVE_ID>/SAFE_RUNTIME_CONTEXT_V1.json
```

## 真实目标审计基线

`RESEARCH_OBJECTIVE_EVOLUTION_V1_BE80F967D29706F19703C869` 的安全上下文应保持：

- 有效状态为 `AI_DESIGN_AWAITING_CONFIRMATION`，有效阶段为 `AI_DESIGN_APPROVAL`；
- Candidate、Durable Contract、Trial 均为 0；
- 预算为 `0/4`，剩余 4；
- 构建过程不改变真实研究工作区文件。
