# MECHANISM DISCOVERY STANDARD

## 原则
- 一个 Factor 不等于一个 Mechanism。
- Mechanism 必须可解释、可证伪。
- 每个主要 Factor 至少提出 2 个 alternative explanations 并尝试证伪。
- 融合必须 Hypothesis-driven，禁止 all-pairwise 组合爆炸。

## 优先级机制
T+1 delayed supply / Overnight-Intraday asymmetry / Smart-Informed Money / Flow Absorption /
Leader-Follower / Sector Diffusion / Limit-Up Quality / Failed-Limit Recovery / Market Sentiment /
Volatility Compression / Return Path Quality / Price-Volume Confirmation / Chip-Disposition。

## 记录字段
primary_mechanism_id, secondary_mechanism_ids, mechanism_confidence, alternative_explanation。
