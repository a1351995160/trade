# 零账户日的一次版本接续

本协议用于已暂停、尚未提交任何账户交易日的 `LONG_HORIZON_SEGMENTED_V1` 双成本任务。它保留原账户用途、原 START、原计划和累计收费，在独立 Owner 批准下接入精确的新执行版本。普通 RESUME 不具备切换版本的权限。

当前唯一业务替换是 `universe_account_inputs_v1.py` 的初始化优化：已知开盘状态时省去重复的收盘状态查询；开盘未知仍核查收盘。父池资格、子输入物理与逻辑核验、交易、费用和账户算法保持原语义。公共调度、核验、报告、反馈及会话入口的必要变化逐文件绑定，不允许任意源码替换。

## 授权与计费

能力桥先验证原 Owner 批准及既有版本血缘，将精确批准的新源码身份投影回原合同能力快照。它不创建账户执行权限。账户接续清单再绑定原任务、JOB、PREVIEW、CONFIRMATION、控制链、已结清段、原操作预留、特征提交前缀和精确 CI 版本，由原 Owner 单独批准。

每个任务只有一个与新版本无关的接续 slot。重复安装同一清单返回原引用；不同清单拒绝。安装不派发 worker，不新增 grant、候选、准备、账户用途或预算，不退费。后续段仍经过原 `StrategyBatchGovernanceV1` 和 campaign meter；原累计时间、下一段号、用途限额和到期时间继续生效。

首次安装要求一个账户已自然暂停且无活跃/未知派发，另一个账户仍为原 RESERVED；两者都没有账户 checkpoint 或逐日提交。既有特征只复用提交回执和对应数组切片哈希均通过核验的前缀，不信任未提交尾部。它不支持持仓或账户账本跨版本迁移。

## 执行与证据

原 JOB/plans 始终用于确认、novelty、START、原操作及费用核对。Owner 清单中的 active plan 用于实际 `prepare`、真实 `backend.describe()` 和结果，不能将新源码哈希伪装成旧版本。公共 worker 通过已经验证的版本上下文提供执行授权投影，不改写原确认回执。

新账户段追加独立版本侧车。访问记录、RESULT、独立核账、compute scope、最终报告、PUBLIC_RESULT 和反馈均记录 `account_version_continuation`，包含清单路径/摘要、版本身份、原 JOB 摘要及实际计划身份。公共核验同时校验原授权与收费链、新执行版本和同一版本证明。后续核验只要求已批准的历史前缀不变，允许合法新增交易日和已结清段；不能再次把“当前仍为零日”作为历史核验条件。

父事件已经提交、子镜像尚未写入的崩溃，由专门 reconcile 检查原前缀及父端证明后补原镜像；完成后重新执行严格核验。普通派发不接受父子不一致。没有实际 worker 的镜像恢复段保留原上界收费和未启动证据，不伪造执行回执。

会话接续先核对原事件与父子镜像。有未返回派发或镜像缺口时，只核账、严格重验并返回等待，本次不再派发。已知失败保留实际错误及原任务终态；只有原子用途均已结清且没有活跃或未知段，才结清候选失败。崩溃发生在 `ATTEMPT_END` 保存之后时，重复调用核验原记录并补同一笔结清，不重新运行或覆盖失败原因。

## 公共入口

`scripts/setup_account_version_continuation_v1.py plan` 接受已钉住摘要的 spec，仅规划元信息。`freeze` 要求已在原受保护 Owner 目录登记的能力桥批准引用与账户接续批准引用；CLI 不持有或自动生成 Owner 能力。批准引用 JSON 的内容是原 `approval_id/summary_hash`，文件路径本身不能充当批准。

`scripts/run_account_version_session_resume_v1.py` 专用于已冻结任务：校验原会话配置 ACL、原配置摘要、旧源码 pins 与批准映射、原 PREVIEW/BOUND_REQUEST/FREEZE 及事件链，然后只推进原 task。它不重新 preview、freeze、prepare 或创建任务，也不自行解除 PAUSE。默认每次只推进一个真实受限段，便于核对持久特征和账户日进展；批次循环仍由总授权控制。

未批准源码、闭包外变更、损坏的旧原件、不同任务、首次安装时已有日提交、活跃或 UNKNOWN 派发、到期和原用途剩余时间耗尽均拒绝。历史回执不因授权后来到期自动失效；再次运行仍需当前有效授权。升级后如实际源码不再匹配清单，在线重核会拒绝，必须区分历史有效回执与当前可重核能力。

合成测试只证明协议和工程接线。真实全池性能、账户完成、策略达标、独立验证、正式资格和 Paper 观察各自需要真实证据。

完整504日双成本合成接线测试用 `RUN_LONG_ACCOUNT_VERSION_INTEGRATION=1` 显式启用；常规 CI 校验协议及拒绝路径，明确跳过这个慢速场景。测试提供者冻结完整能力元信息并动态重读源码摘要，不替换 Owner、账户 guard、记账或报告验证。它不作为真实全池限时性能证据。
