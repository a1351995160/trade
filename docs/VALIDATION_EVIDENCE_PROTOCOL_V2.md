# 独立验证准备协议

`validation-preview` 只读核对完整策略家族并列出数据需求，`validation-freeze` 在原研究目录冻结唯一协议，`validation-status` 重读协议并校验策略版本。三个操作通过 `scripts/run_strategy_lifecycle_v1.py` 调用。

预览/冻结配置包括 `strategy_ids`、`symbols`、`not_before`、可选 `route` 和数据元信息报告 `metadata_report`；配置位于档案目录的父目录范围内。路由为 `FUTURE_OBSERVED` 或 `SEALED_HISTORICAL`。

当前可执行的正式路线仍为冻结后采集 60 个预热交易日、504 个账户交易日，需 564 个收盘及 504 个开盘快照、交易所日历、证券状态、换手率和公司行动覆盖。协议不缩短旧统计方法的样本要求。封存历史的独立性和对应方法尚未获得认证，选择该路线会明确显示不支持，不把未知历史升级为独立数据。

正式登记配置可以传入 `protocol_path`。正式服务重新校验协议、完整家族、日期、证券及策略版本，仍独立执行原方法、预算和数据检查。冻结协议本身不消费确认预算，不代表策略合格，也不启动采集。相同请求恢复读取同一协议；改变窗口必须保留旧协议并按新的受控研究过程处理，不能覆盖旧文件免费再试。

元数据报告只帮助发现已暴露历史与缺口，不构成供应商认证或独立性证书。当前方法适用性、公司行动和多证券范围的限制依然生效。
