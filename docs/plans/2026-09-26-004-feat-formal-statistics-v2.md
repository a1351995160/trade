# 正式评审尺子 V2：先固定方法，再验收误判和识别能力

## 目标与边界
保留V1源码及全部失败记录。V2保持504日扣费后日简单超额收益均值这一问题，固定8个连续63日组均值，以t7单侧检验和完整候选家族Holm判断。候选最多5个，终生3批预算仍为.025/.015/.010，实际水平仍为预算的一半。不得根据校准结果选择组数、种子、场景或门槛。

依据Ibragimov–Müller原论文 https://www.princeton.edu/~umueller/tstat.pdf 。8组共同均值、近似独立正态的条件下单侧低水平检验有依据；504日分段不自动证明这些条件。有限DGP校准通过仅表示在预先约定的范围通过，不是市场普遍有效或未来盈利保证。
