# 长历史真实行情账户适用性研究

用户授权：继续走通长历史候选、费用压力和持有基准验证；常规选择自主执行。此研究不授予独立确认资格。

## 固定设计
- 原5个归档候选，规则不改；000001.SZ和600000.SH两只证券不变。
- 行情请求2022-01-01至2024-07-31。选择截至原探索终点2024-07-31的最后564个真实交易日，前60日预热，后504日账户。依据日历选择，不按收益挑窗口。
- 5候选各BASE/STRESS与1个等权持有BASE，共11个账户；固定100万资金与原费用模型。不新增参数搜索。
- 新记录为HISTORICAL_MODELED研究；日线开盘成交和历史状态时间是建模假设，禁止伪造observed快照。原正式确认和统计来源保持冻结。
- 公司行动、停牌和数据矛盾必须核实或明确失败，不能为跑通直接声明覆盖完整。

## 实现单元
### A：固定历史数据
Goal：取得完整原始响应、真实日历、日线、turn、状态、分红及来源。
Files：外部研究目录real-process-504-v1/data与专用采集脚本；不覆盖旧文件。
Approach：BaoStock匿名日线接口及已有文件交叉核验。保留抓取时间、请求和来源hash；无缺口才能物化。
Verification：两证券相同564日，504执行状态，行动与前收盘核对，旧数据交集差异报告。

### B：历史账户适配
Goal：复用公共策略入口、同一引擎与独立核账，不假造实时采集。
Files：formal_account_backend_v1.py最小兼容改动、新historical_process_v1.py、对应测试。
Approach：历史适配明确拒绝真实快照、限定HISTORICAL_MODELED；描述/输出绑定模式；建模开盘用原run_chain非observed路径。正式入口时间约束不放宽。
Verification：历史连续窗口、BASE/STRESS/基准、分红、错误模式与快照混入拒绝、正式入口仍拒绝缺快照。

### C：固定执行和适用性诊断
Goal：真实运行11账户并核对可重复性、超额收益与8组统计；给出有边界的研究结论。
Files：专用runner、报告、业务文档、progress.md。
Approach：复用StrategyBatchGovernanceV1记录新明确授权的固定适用性研究曝光；不重置旧预算或伪称新规则。执行前保存计划/输入/来源，结算失败也保留。描述性依赖/分组敏感性不能自动升级为适用性证明。
Verification：11条开始/结算，504逐日现金持仓核对、确定性重放、配对基准日期严格一致；统计仅研究诊断，独立资格始终false。

## 边界
独立确认需要实际隔离证据，未知文件不默认独立；不缩短已校准504日设计，不自动启动Paper/券商交易。若实际发现额外可修复缺陷，保持固定规则与窗口修复工程问题并保留失败，不要求用户逐项确认。
