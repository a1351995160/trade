## 为什么不直接跑一个检验看看

V2评判的是扣费后日收益减去同口径持有基准后的均值，不是原始账户收益。当前既缺足够长度，也缺档案中的正式配对基准，因此没有计算正式p值，更没有将118日重复、补零或把分组缩短来凑504日。

分组近似独立、近似正态且具有共同期望是这把尺子的条件。原论文明确讨论了分组选择需要事先的相关结构知识，不能全部交给同一批数据决定。[Ibragimov–Müller原论文](https://www.princeton.edu/~umueller/tstat.pdf)

因此，未来即使“自相关检验不显著”或“正态性检验没拒绝”，也只能是诊断信息，不能自动写成适用性已证明。真实策略的持仓切换、空仓、费用和市场状态需要纳入事先固定的适用范围及账户过程压力校准；不能看完确认收益再选择最有利的分组或方法。

## 接下来能怎样推进

当前阶段：**历史账户核对完成 → 真实收益适用性证据不足 → 独立确认尚未执行 → 暂无正式策略资格**。

1. 使用已经暴露的历史数据做适用性研发：通过公共账户入口，形成连续504日的候选BASE、STRESS及等权买入持有基准，逐日配对核账。这个阶段允许发现方法不适用，结果只作开发证据，不授予策略资格。
2. 在查看独立确认收益之前，固定适用性审查方案、支持范围和失败处理；对实际持仓及费用机制做过程校准。不得仅增加一个可手填的“适用”开关。
3. 独立证据有两种不同情况：若能找到有完整隔离及访问记录的历史保留集，可先审计并另行设计历史确认协议；当前实现仅接受冻结后的前瞻采集，不能直接导入旧文件冒充该协议。若没有历史保留集，则按现行规则先冻结再采集60个预热日和504个账户日，真实时间超过两年，今天无法完成。
4. 以上条件齐备后，再运行完整家族的正式评审；通过后才讨论Paper。本次没有注册会消耗预算的确认批次，也没有启动长期采集或交易。

应当修正预期：V2模拟通过是必要的研发证据，不意味着只剩一个快捷验收按钮。当前最值得先完成的是第1步的真实行情账户过程研究，并据此把第2步的适用边界设计清楚；独立确认数据的准备可随后按实际可用来源确定。
