# Paper 预登记观察与退出

新会话可通过 `ForwardPaperSessionV1.create(..., observation_policy=...)` 冻结观察要求。旧会话和未传入该参数的新会话保持原行为。

```json
{
  "version": "PAPER_OBSERVATION_POLICY_V1",
  "min_complete_days": 20,
  "review_after": 60,
  "max_drawdown_bps": 1500
}
```

`min_complete_days` 是作出观察结论所需的最少完整交易日，`review_after` 是预先固定的评审交易日数，`max_drawdown_bps` 是账户相对已观察权益峰值的回撤阈值，1500 表示 15%。日数必须为正整数，最少日数不超过评审日数；日历至少包含初始准备日、全部评审交易日以及一个后续退出交易日，即长度至少为 `review_after + 2`。初始只有 CLOSE 的信号准备日不算完整观察日。额外一天提供合法退出机会，不保证停牌或跌停持仓必能在该日成交。

系统在实际可见 OPEN、CLOSE 及成交风险校验时检查权益。达到回撤阈值后显示 `RISK_EXIT_ONLY`；达到评审日数后显示 `REVIEW_DUE`。两种情况下都不再增加买入，收盘计划对已有持仓给出退出，保留原交易所状态、T+1、停牌、价格限制和费用校验。出现卖不出去的持仓不会被删除或按假价格清算，仍等待下一合法执行阶段。风险锁不会因为价格反弹、重启或重复提交快照而解除。

峰值权益、最大回撤、完整日数、风险锁和原因存入原阶段状态，并经过原快照重放核对。没有新的资产账本或独立的可手改风险状态文件。正式组合继续使用精确政策绑定，不能借新建 Paper 悄悄改变已评审组合的观察政策。

状态同时展示 `minimum_sample_reached` 与 `observation_qualified=false`。达到天数、风险没有触发或收盘退出都不证明策略有效，也不授予新的真实资格。合成会话不增加真实观察日。本版是固定时点评审准备与风险退出控制，不把停止买入误称为已经完成统计评审。

这里观察的是阶段快照，不是连续盘中行情；阶段间发生而未被采集的回撤不能由本功能证明。真实长期观察仍按实际到达交易日逐步积累。
