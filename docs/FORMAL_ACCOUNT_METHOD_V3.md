# 五万元 V3 账户方法研究

本次结论为 **UNSUPPORTED**：不能把原八组 t7 + Holm 方法直接推广为不限制共同状态的五万元 V3 账户评判方法。真实资格继续等待；这不是所有统计方法都不可能适用的结论，也不影响授权探索。

## 冻结范围与检验对象

原理论要求各组估计量具有共同均值并近似独立、近似正态，见 [原论文](https://www.princeton.edu/~umueller/tstat.pdf)。真实离散持仓、现金闲置和长期共同状态不自动满足这些条件。历史诊断不显著不能证明独立性。

在读取本研究账户结果前，`scripts/study_formal_account_method_v3.py` 以排他创建冻结完整协议、策略、现金基准与源码哈希。只研究一个方法、一个两点共同状态过程：

- 50,000 元；三股 `000001.SZ`、`000002.SZ`、`600000.SH`；三持仓；单股上限 3,000 bps、目标权重 0.3；整手、次日开盘、BASE 费用。
- V3 收盘买入、252 日持有后退出再入场；无风险退出、无公司行动；504 个账户日，80 日热身。持仓过程由真实公共账户引擎执行，不直接生成账户收益。
- 股票价格为 `10 + sign * 0.01 * max(account_index - 1, 0)`，整条路径共同符号正负各半。完整枚举两个原子；额外常价对照和确定上行功效原子。日历与价格均为专用合成资料。
- 现金基准零利息，五个完全相同的预冻成员使用同一经济路径；完全相关也属于未限定依赖的家族，未搜索成员或只报告赢家。
- 新范围要评判的零假设为“504 日时间平均期望每日净简单超额不大于零”。它明确不同于原定理的共同组均值假设。八组 t7 + Holm、实际检验 alpha 0.0125、家族错误率门槛 0.025、该固定上行原子的功效门槛 0.7。
- 完整枚举而非抽样估计，不需要 Monte Carlo 置信区间。仅一个生成过程的强效应功效，不代表其他效应大小的检出能力。读到结果后不调整生成过程或换方法。

六个账户均执行 `RuleAccountBackendV2` 及其逐日独立持仓、成交价格、费用、现金、权益核账。所有资料仅为方法研发，未读取确认集、未调用模型、未消费真实研究候选或确认额度。

## V3 接口与资格隔离

`formal_rule_adapter_v3.py` 提供显式 `execution_scope`、`prepare_rule`、`run_rule`、`validate_result` 及 `method_resolver(scope)`。不改旧 V2 的两股百万范围常量。账户执行成功不代表方法获准。

resolver 返回 `applicable=False`、方法 ID、请求范围哈希和合成方法研发 profile；只有报告内容符合固定哈希时才返回 `evidence_hash`，它标识“不支持”的研究证据。报告缺失或篡改时证据哈希为空且仍不适用。调用方的 `method_approved` 等布尔值不能更改结论。`require_publication` 拒绝所有当前请求，合成测试不会创建真实资格。
