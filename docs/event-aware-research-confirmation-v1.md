## 推荐的新信号合同

新身份：EVENT_AWARE_GROSS_RETURN_5D_PROPOSAL_V1，不覆盖RETURN_5D或registry。输入是六个相邻独立交易session的RAW收盘价、五段经核验的事件调整。对于区间(t-5,t]，单期因子为：

`g[d] = ((1+s[d])*close[d] + cash[d]) / close[d-1]`

`signal[t] = product(g[t-4], ..., g[t]) - 1`

s为每一旧股新增的免费股份，cash为每一旧股税前现金分配，均必须明确单位及除权生效日；多事件同日必须由输入适配器形成一个有依据的合并条款，不能在此任意相加。只支持普通现金分红、免费送股/转增及明确无事件。配股、合并、拆分、选择权或其他未定义事件全部不可计算；不可计算不填0、不按已有绩效删证券或替换候选。

这是合成验证的信号模型，采用除息日收盘再投入的税前总回报含义，不是账户实际现金流。现金未到账、股票未上市仍不得用于真实账户买卖；原账户费用和退出不被信号公式替代。[MSCI方法文档](https://www.msci.com/eqb/methodology/meth_docs/MSCI_Index_Calculation_Methodology_20240301.pdf)支持总回报区别于价格回报、在除息日处理分配的基本思路；本提案不是声称完全实现该指数方法或其市场覆盖规则。

可见性：仅使用事件已生效且条款在决策前已知的版本，实际更晚时间优先。单有公告日期时，保守以公告日之后首个交易session开盘可见；该时间是显式建模，非真实发布时间。事后半年报只用于验证事件事实，不证明当时已知。无完整事件覆盖证据时返回ACTION_COVERAGE_UNPROVEN，不能因gbbq没有记录自动生成VERIFIED_NONE。
