# 主板与创业板历史交易制度 V1

这份制度让深圳主板、上海主板、创业板使用同一套研究流程，并按各自当时的交易制度判断能否成交。它不改变旧 V2 后端已经冻结的语义。

## 已接通的制度范围

| 情形 | 本版处理 |
|---|---|
| `00xxxx.SZ`、`60xxxx.SH` | 普通日 10%，风险警示日 5%；风险警示不允许新买，既有持仓按可成交条件退出 |
| `30xxxx.SZ`（含来源别名 `GEM`） | 2020-08-24 前普通日 10%、风险警示日 5%；该日起二者均为 20% |
| 创业板自 2020-08-24 起上市、主板自 2023-04-10 起上市 | 上市后的前五个交易日无日涨跌幅限制，第六个交易日起按对应制度 |
| 改革前的新股上市首日 | 正确识别全天发行价 64%—144% 的非对称范围；开盘执行明确阻断，不能把全天范围当开盘集合竞价范围 |
| 价格边界 | `Decimal` 按四舍五入取至 0.01 元；2023 制度要求至少移动一个价格单位，旧沪市风险警示股票前收低于 0.10 元时也按绝对上下 0.01 元处理 |
| 买入数量 | 100 股的整数倍；退出、T+1 和剩余零股仍由账本/订单共同核对 |
| 停牌 | 由冻结的当时证券状态判断，停牌时不成交 |
| 未知、矛盾板块或上市身份 | 阻断；不回退主板、正常状态或虚构上市日期 |

制度计算区间明确限定为 **2014-06-13 至 2025-07-31**，与本次已有历史数据上界一致。它不是当前实盘交易制度声明；超出此区间需要新的来源核验和版本，不能继续沿用此版。

“无日涨跌幅限制”只表示不以普通日 10%/20% 限制作错误拒绝，并不表示任意订单一定成交。日线开盘模型仍依赖冻结的状态、真实开盘价和上一交易日可用流动性；没有队列、集合竞价申报和盘中临时停牌资料，不得宣称已经精确复现交易所撮合。

旧新股首日开盘集合竞价是发行价 80%—120%，与全天的 64%—144% 不同。现有日线无法证明哪笔价格由开盘集合竞价产生，因此 `UNSUPPORTED_LEGACY_IPO_OPENING_DAY` 明确保留缺口。重新上市、退市整理、交易所特别安排等特殊交易日同样阻断，不能套普通日规则。

## 当时可见的输入和身份

板块必须由证券代码、交易所后缀、来源板块三者共同确认；保留 `source_board`，并把 `GEM` 归一为 `CHINEXT`。不能把所有深圳股票写成 `SZ_MAIN`。

上市日期来自具备来源的数据，不能用缓存第一根行情作为上市日。上市日位于冻结日历之前时，只在冻结日历已经观察到至少五个交易 session，或源资料明确证明之前已有至少五个上市 session 时，认定上市特殊期结束。这只证明特殊期已过，不虚构准确上市天数。证券状态的可见时间仍由上游资格门和 `SecurityMaster` 检查。

`describe_board_policy_v1()` 返回来源 URL、原响应字节 SHA-256 和制度语义；`board_policy_identity()` 对整个描述计算稳定身份。数据准备、计划、缓存和独立核验须冻结同一个身份。原响应哈希来自 2026-10-01 对官方地址的有界只读核验，不表示官网页面未来不会变化；联网获取不能成为账户执行时的隐含依赖。

`BoardExecutionPolicyV1.resolve()` 返回具体证券交易日的制度描述。`BoardPriceLimitModelV1` 保持 Broker 的开盘可买/可卖接口，在开盘仅使用开盘价、交易所参考前收价格和冻结证券状态；不读取当日最终最高价、最低价或总成交量判断开盘可成交。

达到涨停价买入或达到跌停价卖出时，日线无法证明队列位置，因此保守等待。离价格边界一个 tick 的价格不会因旧 98%/102% 的近似阈值被误当作已经涨跌停。制度以输入中的交易所参考前收价计算涨跌停，不能以指标用复权价格替代。

新全范围账户还检查加入模型滑点后的成交价：即使原开盘价合法，模型成交价若越过当日价格边界，也以 `MODELED_FILL_PRICE_OUTSIDE_DAILY_LIMIT` 拒绝。系统不会把超界价格夹回边界再声称成交；正常和压力成本都适用这项检查。

- [深交所创业板交易特别规定 ABC（一）](https://investor.szse.cn/institute/rules/t20200807_580310.html)：改革前后普通、风险警示比例及新股首五日规则。
- [深交所 2020-08-21 新闻发言人答记者问](https://www.szse.cn/aboutus/trends/news/t20200821_580924.html)：改革自 2020-08-24 生效，存量股票同步调整。
- [深交所 2014 年新股上市首日通知](https://www.szse.cn/www/disclosure/notice/company/t20140613_508770.html)：全天与开盘有效申报价范围分别规定。
- [深交所交易规则 2020 年旧版原 PDF](https://www.szse.cn/lawrules/rule/repeal/rules/P020231230545338442079.pdf)：旧普通交易制度及 A 股数量、报价单位。
- [深交所主板交易问答（2023 年第 2 期）](https://investor.szse.cn/knowledge/qa/t20230306_599093.html)：主板普通 10%、风险警示 5%、上市首五日规则。
- [深交所主板投资入市手册（十五）](https://investor.szse.cn/institute/rules/t20230706_601604.html)：主板与创业板均为 100 股买入单位、A 股 0.01 元报价单位。
- [上交所交易规则 2023 年旧版原 DOCX](https://www.sse.com.cn/lawandrules/sselawsrules2025/repeal/rules/c/10824490/files/dcbe58edb194451d93f19b1f7dd8fb4c.docx)：3.3.8、3.3.11、3.3.13、3.3.17、4.4.10 的数量、价格边界与风险警示制度。
- [沪深主板首批注册制上市安排](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20230404_5719112.shtml)：首次上市日为 2023-04-10。
- [上交所 2014 年首日交易机制说明](https://english.sse.com.cn/news/newsrelease/c/4947622.shtml)：改革前首日的开盘、全天有效申报范围区别。
- [上交所 2013 年每月问答（一）](https://edu.sse.com.cn/best/article/mcontent/c/4731114.shtml)：沪市风险警示 A 股前收低于 0.10 元时，绝对涨跌幅为 0.01 元。

2025-06-27 的主板风险警示 5% 改 10% 通知当时属于征求意见与技术准备，不能将拟议制度提前应用到 2025-07-31 前的历史账户。2026 年规则变更也不属于本版冻结历史范围。

## 验证的含义

`test_board_execution_policy_v1.py` 使用合成证券身份和手算价格，验证板块混标、规则生效、第五/第六上市 session、舍入、缺失与政策身份变化等反例。它证明政策实现的工程边界；真实创业板数据、三类退出成交、分红和恢复一致性仍由全范围账户验收提供，不能由合成测试替代。
