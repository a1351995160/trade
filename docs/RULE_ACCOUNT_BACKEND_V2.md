# 有持仓状态的多股票策略账户

`ResearchRuleStrategyV2` 通过原 `strategy_interface_v1.prepare/run` 进入 `RuleAccountBackendV2`。日线回测和前瞻账户复用 `ForwardPaperEngineV1`，买卖仍经过原订单、成交、风控、持仓和资金账本。

持有期从实际买入成交开始，冷却期从实际清仓开始。未成交的卖出意图不能把账户变成空仓；部分成交后的剩余持仓继续退出。各证券的规则状态单独保存，所有证券共享同一笔资金。

## 两种数据用途

- 默认 `execution_profile='HISTORICAL_MODELED'`：读取已核验原始日线、供应商换手率、证券状态及现金分红。日线开盘价及此前交易日成交量用于模拟成交；历史状态可见时间仍是建模假设。允许一只或多只沪深主板股票。
- 显式 `execution_profile='OBSERVED'`：消费独立证据服务组装的实际开盘、收盘快照，使用其接收时间与开盘报价。不能把历史数据改个标签就用于正式评审；权威评审先验证来源、冻结时间、独立窗口和完整覆盖。当前正式评审仍限定两只股票、100 万初始资金、单股最多 50%，新股票池研究不能自动继承这一统计范围。

两种模式都不直接授予策略资格。真实观察模式也是模拟账户，不接券商下单。

预热只准备指标，不产生评价期第一天开盘的订单。首个决策在 `account_start` 收盘形成，最早在下个交易日开盘执行；这一约定写入账户计划，与原真正买入持有基准及 Paper 的首个收盘阶段一致，避免多一天持仓机会造成不公平比较。

## 输入与拒绝条件

窗口明确证券、完整交易日历、预热起点、账户起止日期。至少 60 日预热；日线、换手率和账户期状态必须覆盖冻结证券日期的完整矩形，缺数、未支持的停牌特征、未知公司行动与税务条款会拒绝。

现金分红只在生效后改变指标价格；成交、资金和市值继续使用未复权行情。旧个人红利模型仍不支持登记后、付款前出售获息股份；遇到这类事件时停止，不补造到账或税款。

## 核验

每个收盘按逐笔成交、原始价格、费用参数、独立 FIFO 持仓及原始分红条款重建现金、红利税和权益，与引擎账本比较。输出 `daily_accounts`、`fills`、决策和最终账户，保留现金及权益差额。该核账证明账户计算一致，不证明交易规则有盈利能力。

测试覆盖持有和冷却、三股共用资金、两种费用、空仓分红、持仓分红补税、真实快照时刻模拟成交及重复执行。测试数据明确为合成；真实历史输入及运行证据另见交付报告。
