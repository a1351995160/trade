# 受限研究与固定账户工具

本次发布代码与合成测试，不包含研究输入、真实回测结果、运行回执或内部研究日志。脚本中的本机路径是部署时需要核对的显式依赖，仓库克隆后不能自动取得这些文件或运行许可。

数据适配分别处理RAW成交价格与HFQ信号，保留时点未知、停牌、公司行动风险及来源冲突。研究执行须经过输入身份、冻结合同、新颖性、可行性及原预算/授权服务，不得通过修改本地JSON或合成标志绕过许可。

`fixed_account_rules.py`为固定账户回测和只读预览共用入场排序、可用时间、Top3、事件拒绝和逐lot退出。`fixed_account_preview.py`使用账户副本，区别缺数据与无信号，并保留部分卖出后的剩余持仓。预览不创建真实订单，不代表研究资格。

历史脚本包括统计方法提案、输入证据核验、受限获取和恢复。代码存在不表示相应方法获准，也不授予行情访问、绩效实验、Paper或实盘权限。已完成请求仅在身份/哈希一致时复用，恢复须保留失败与实际资源消费。

`show_baostock_progress.py --watch`每轮读取本地回执后等待60秒；Ctrl+C仅退出观察。它不重试请求、不增加预算、不启动回测。

测试必须使用`CHANLUN_TEST_ISOLATION=1`；Windows需要使用NTFS临时目录运行依赖硬链接的治理测试，不能通过跳过保护断言使检查通过。现有Windows OPEN事件继续保留。
