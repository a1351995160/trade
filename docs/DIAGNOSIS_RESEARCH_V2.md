# 有状态规则：诊断后生成，再做固定初筛

`DiagnosisResearchV2` 把新的买卖条件、持有期、冷却期候选接到原研究预算、公共账户和完整家族档案。统一生命周期的实现类型为 `DIAGNOSIS_V2`。

第一版范围固定为两只股票、100 万初始资金、最多两只持仓、单股最多 50% 暴露、504 个账户日。先验证旧完整家族的结算结果，只把成本和分段失败的定性原因交给模型。在第一次模型调用前，同时冻结数据窗口、规则账户输入身份、真正买入持有账户输入身份、初筛标准及预算。两种后端的身份算法不同，必须分别保留，不能通过改写身份假装相同。

每个合法候选先归档，再运行普通成本与压力成本账户；使用同日真正买持账户，按原冻结标准检查正净收益、最大回撤不超过 25%、两个 252 日段均有正的日净超额收益之和。状态规则在费用变化后可能有不同交易过程，因此核验相同规则、风险设置和执行费用，不强迫两个费用情景的决策逐条相同。完成本候选初筛后，下一次模型才获得其定性反馈。非法或重复候选仍占尝试额度；失败家族成员不会被删除。

正式登记从结算凭证、账户结果和初筛配置重新计算通过名单。所有 V2 正式登记必须提供有效初筛根目录；失败者仍保留在冻结家族及多重检验分母，只为通过初筛者开独立数据账户。历史初筛不是统计有效性证据，现有真实收益方法适用性及 V2 方法范围阻断继续有效。

## 实际运行

在源码稳定后执行，两个命令之间不能更改源码：

```powershell
$env:PYTHONPATH='src;.'
python scripts/run_diagnosis_research_v2.py create --root <新的研究目录> --seed-root <旧11账户目录> --data-root <历史data目录> --approval-statement '按完整计划执行两次有预算规则研究' --attempts 2 --json
python scripts/run_diagnosis_research_v2.py run --root <同一研究目录> --json
```

`status` 只读；`revoke` 撤销未完成工作；`handoff --calibration-path ... --not-before YYYYMMDD` 仅在有候选通过初筛时登记未来窗口。无候选通过不会消耗正式确认机会。模型中断无可验证回执、账户未结算等情形拒绝自动重试，不退还尝试额度。

合成 504 日测试证明编排、完整家族、成本初筛、定性反馈、正式交接及拒绝结论能贯通；真实数据和真实模型运行需另看运行目录的原始凭证，不能用测试结果替代。

## V3 公共入口迁移

`DiagnosisResearchV3` 使用维护者登记的 `ResearchCampaignV1` 和 `StrategySubmissionV1`，股票池、窗口、资金、成本与初筛门槛在创建时冻结。每个合法提案复用公共 `preview → freeze → approve` 和 `start` 的同一固定账户执行阶段，核验与报告移入受限 worker；账户授权明确绑定 campaign 引用、三个账户计划及操作身份，不从数据读取授权推导交易权限。

调用 `create` 后使用 `run()` 跨批继续；宿主使用 `tick()` 每次至多推进一个未完成候选，已完成记录仅校验后跳过，让观察队列获得调度机会。`status()` 返回剩余次数、下一候选及暂停、未知、完成状态；更换模型时用同一 campaign、submission 和新 invoker 重新构造服务。已持久化候选保留父规则、机制假说、修改理由、反证标准、能力快照及定性失败事实。`confirmation_material()` 输出完整尝试家族、选择规则、探索暴露和预算身份；初筛通过仍不是独立验证或策略资格。

候选、数据实验、账户、模型调用、token、费用、核验及运行时间共用总预算。未知模型结果保留预留且不自动重调；没有消费回执的恢复不能冒充零消费。数据准备和核验均由固定受限 worker 执行，启动前安装内存和时间限制，保存请求、握手、启动、结果和资源凭证；未知或失败进程不会自动重派。核验整组实测耗时保守计入各核验操作。账户由公共受限进程按授权时间上限执行。自动研究创建前要求维护者注入的可信模型适配器通过 `enforce_budget_limits` 安装并证明 token/费用限制；只有说明字符串或上限数字会被拒绝。当前默认 Codex 适配器没有这一供应商保障，所以自动研究创建失败关闭，真实模型接线成功不解除此限制。合成测试适配器明确标识无真实费用，不代替供应商保障。

合成模型的两批公共账户测试与真实模型接线证据分开：`reports/trusted_workflow_acceptance/model_smoke` 记录一次真实无工具 JSON 提案及 V3 解析结果，没有执行该提案账户，费用状态为 `UNKNOWN`，不能由此声称真实收益、独立资格或费用硬上限已经验证。所有候选失败时按冻结尝试额度正常结束，不放宽门槛续跑。
